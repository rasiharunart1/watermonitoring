1. Arsitektur Sistem

Dua node terpisah dipakai agar CPU ESP32-CAM tidak dibebani pembacaan ADC/timing OneWire, dan sensor tidak rebutan radio WiFi dengan stream video.

Alur data: node sensor dan kamera mempublikasikan ke backend FastAPI pada satu origin sehingga dashboard bebas dari masalah CORS.

2. Hardware & Wiring

2.1 Node Sensor (ESP32)

Skema wiring diagram breadboard untuk Node Sensor ESP32: Modul pH (GPIO 34), Turbidity (GPIO 35), DS18B20 dengan pull-up 4.7 kΩ (GPIO 4), dan Modul Relay (GPIO 27 / RELAY_PIN).*

SensorPin ESP32Catatan
Modul pH (output analog)GPIO 34ADC1, toleran 0–3.3 V
Modul Turbidity (output analog)GPIO 35ADC1
DS18B20 (data)GPIO 4pull-up 4.7 kΩ ke 3.3 V
Relay (IN)GPIO 27modul relay umum aktif LOW (RELAY_PIN 27 di firmware)*
GND semua sensorGNDreferensi ground disamakan
Catatan Pin Relay & ADC Pada firmware watermonitoring_esp32.ino, pin relay didefinisikan pada #define RELAY_PIN 27. Jika perakitan fisik menggunakan pin lain (misal GPIO 12), pastikan nilai RELAY_PIN pada firmware disesuaikan.
GPIO 34 & 35 adalah input-only, aman untuk baca analog. Jangan gunakan pin ADC yang ikut dipakai radio WiFi.

2.2 Kamera (AI Thinker ESP32-CAM)

Pin kamera sudah dikodekan di firmware — untuk board AI Thinker ESP32-CAM tidak perlu diubah. Jika memakai clone/M5Stack, baris konfigurasi di camInit() yang harus disesuaikan.

  2. Install library §3, pilih board ESP32 Dev Module.

6. Penjelasan Kode: Water Monitoring

6.1 Include & Definisi Pin

#include <OneWire.h>
#include <DallasTemperature.h>
#include <Preferences.h>

#define PH_PIN    34
#define TURB_PIN  35
#define TEMP_PIN  4
#define RELAY_PIN 27
#define ADC_VREF  3.3f
#define ADC_MAX   4095.0f

OneWire + DallasTemperature adalah stack DS18B20. Preferences menyimpan kalibrasi ke NVS agar tetap ada setelah reboot/blackout. ADC_VREF/ADC_MAX mengonversi ADC (0–4095) → volt (0–3.3 V).

6.2 Model Kalibrasi Linier

// y = slope * volt + offset (kalibrasi 2 titik)
struct Cal { float slope, offset; bool valid; };
Cal calPH = {1.0, 0.0, false}, calTurb = {1.0, 0.0, false};

valid=false berarti belum dikalibrasi → program mencetak voltase mentah, bukan angka tebakan. Ini mencegah nilai pH/turbidity bohongan.

6.3 Pembacaan & Averaging

float readVolt(int pin) { return analogRead(pin) * ADC_VREF / ADC_MAX; }

float applyCal(Cal c, float volt) { return c.slope * volt + c.offset; }

float avgVolt(int pin) {  // 64 sampel untuk buang noise
  float s = 0;
  for (int i = 0; i < 64; i++) { s += readVolt(pin); delay(5); }
  return s / 64.0f;
}
  • readVolt — konversi ADC mentah → volt.
  • applyCal — terapkan model linier slope/offset.
  • avgVolt — 64 sampel (≈320 ms) untuk meredam noise analog.

6.4 Helper Input Serial

bool waitYes() {
  while (!Serial.available()) delay(10);
  String s = Serial.readStringUntil('\n'); s.trim();
  return s.equalsIgnoreCase("y");
}

float readFloat(const char *prompt) {
  while (true) {
    Serial.println(prompt);
    while (!Serial.available()) delay(10);
    String s = Serial.readStringUntil('\n'); s.trim();
    if (s.length() > 0) {
      float v = s.toFloat();
      if (v != 0 || s.indexOf('0') >= 0) return v;
    }
    Serial.println("Input salah, ulangi.");
  }
}

waitYes blocking menunggu tombol y. readFloat memvalidasi input numerik (menerima 0 sebagai angka lewat trik indexOf('0')).

6.6 Kalibrasi 2 Titik

void calibrate(const char *name, const char *key, int pin, Cal &c) {
  float v1, y1, v2, y2;
  v1 = avgVolt(pin);
  y1 = readFloat("Masukkan nilai referensi titik-1:");
  v2 = avgVolt(pin);
  y2 = readFloat("Masukkan nilai referensi titik-2:");

  if (fabsf(v2 - v1) < 0.001f) { return; }  // guard pembagi nol

  c.slope  = (y2 - y1) / (v2 - v1);
  c.offset = y1 - c.slope * v1;
  c.valid  = true;
  saveCal(key, c);
}

6.6a Kalibrasi pH Dinamis (calibratePH)

Gunakan dua larutan yang tersedia, misalnya buffer pH 7 dan pH 9. Setelah tegangan setiap titik diukur, masukkan hasil aktual dari pH meter konvensional (contoh 7.02 dan 8.96). Nilai referensi tidak dikunci di kode dan harus berada pada rentang 0–14.

6.7 Kalibrasi Offset pH (short probe)

void calShortPH() {
      float v = captureShortVoltage();   // tampil realtime, ketik y saat stabil
  if (v < 1.0f || v > 4.0f) { /* peringatan wiring */ }
  float targetPH = readPHReference("Masukkan pH target untuk kondisi short:");
  calPH.offset = targetPH - calPH.slope * v;
  calPH.valid = true;
  saveCal("ph", calPH);
}

Kalibrasi 1 titik (offset saja): slope tetap dari kalibrasi 2 titik. Saat opsi 6 berjalan, ESP32 menampilkan tegangan PH_PIN secara realtime setiap 500 ms. Tidak perlu multimeter; ketik y saat tegangan stabil, lalu masukkan target pH untuk kondisi short (biasanya 7.00 jika mengikuti titik netral modul). Opsi ini tidak menggantikan kalibrasi dua buffer.

6.8 setup() & loop()

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);       // 0..4095
  analogSetAttenuation(ADC_11db); // rentang ~3.3V
  pinMode(RELAY_PIN, OUTPUT);
  setRelay(false);                // relay aktif-LOW: false = MATI (tulis HIGH) saat boot
  ds18b20.begin();
  loadCal();
  Serial.println("\nWater Monitoring ESP32 siap.");
}

loop() adalah menu sederhana: cetak menu → tunggu input → switch atas karakter pertama → aksi → kembali cetak menu.

7.2 Konfigurasi Kamera

bool camInit() {
  camera_config_t cfg = {};
  // ... pin sesuai board AI Thinker ...
  cfg.xclk_freq_hz = 20000000;      // clock sensor kamera
  cfg.pixel_format = PIXFORMAT_JPEG; // output langsung JPEG
  cfg.frame_size   = FRAMESIZE_QVGA; // 320x240, ringan
  cfg.jpeg_quality = 12;             // 0..63, makin kecil makin bagus
  cfg.fb_count     = 1;
  cfg.fb_location  = CAMERA_FB_IN_DRAM;
  if (psramFound()) {
    cfg.frame_size  = FRAMESIZE_SVGA;   // 800x600
    cfg.fb_count    = 2;
    cfg.fb_location = CAMERA_FB_IN_PSRAM;
  }
  return esp_camera_init(&cfg) == ESP_OK;
}
  • PIXFORMAT_JPEG → sensor menghasilkan JPEG langsung (hemat bandwidth).
  • jpeg_quality=12 → kualitas tinggi (0–63, 0 = terbaik).
  • Tanpa PSRAM: QVGA + 1 buffer DRAM. Dengan PSRAM: SVGA + 2 buffer.

7.3 Handler Endpoint & MJPEG (Dual Server Port 80 & 81)

// Port 80: REST API & Web UI (non-blocking)

8. Kalibrasi: Konsep, Rumus Matematika, & Penerapan di Kode Implementasi

8.1 Model Matematika Linier (y = m·V + b)

Sensor analog pH dan turbidity menghasilkan tegangan analog (0.0 V – 3.3 V). Hubungan antara tegangan keluaran (V) dengan nilai fisik (y, berupa derajat pH atau satuan NTU) dimodelkan sebagai persamaan linier:

y = m × V + b
  • Probe pH: Memiliki kemiringan negatif (m < 0). Pada pH rendah (asam), tegangan tinggi. Pada pH tinggi (basa), tegangan turun.
  • Sensor Turbidity: Semakin bening air (0 NTU), cahaya inframerah lolos maksimal sehingga tegangan tinggi. Semakin keruh, tegangan turun.

8.2 Perhitungan Slope dan Offset Dua Titik

m = (y₂ − y₁) / (V₂ − V₁)   ·   b = y₁ − (m × V₁)

Dua titik kalibrasi mendefinisikan garis; offset (b) adalah perpotongan garis dengan sumbu nilai saat V = 0.

8.3 Struktur Data di Firmware dan Penyimpanan NVS

Nilai slope dan offset dibungkus dalam struct Cal dan disimpan ke NVS flash menggunakan library Preferences.h:

// y = slope * volt + offset (kalibrasi 2 titik)
struct Cal { float slope, offset; bool valid; };
Cal calPH = {1.0, 0.0, false}, calTurb = {1.0, 0.0, false};

// Simpan ke Flash NVS
void saveCal(const char *key, Cal &c) {
  prefs.begin("cal", false);
  prefs.putFloat((String(key) + "m").c_str(), c.slope);
  prefs.putFloat((String(key) + "b").c_str(), c.offset);
  prefs.putBool ((String(key) + "ok").c_str(), true);
  prefs.end();
}

// Muat dari Flash NVS saat startup
void loadCal() {
  prefs.begin("cal", true);
  if (prefs.getBool("phok", false)) {
    calPH.slope  = prefs.getFloat("phm", 1.0);
    calPH.offset = prefs.getFloat("phb", 0.0);
    calPH.valid  = true;
  }
  if (prefs.getBool("tbok", false)) {
    calTurb.slope  = prefs.getFloat("tbm", 1.0);
    calTurb.offset = prefs.getFloat("tbb", 0.0);
    calTurb.valid  = true;
  }
  prefs.end();
}

8.4 Penerapan Nilai Kalibrasi pada Runtime (applyCal)

Saat startup, nilai kalibrasi ditarik dari NVS via loadCal(). Pada saat pembacaan sensor:

8.5 Contoh Numerik Nyata (Studi Kasus pH)

  1. Titik 1 (Buffer pH 7.00): Terbaca tegangan rata-rata V₁ = 2.250 V.
  2. Titik 2 (Buffer pH 9.00): Terbaca tegangan rata-rata V₂ = 1.950 V.
  3. Perhitungan Slope (m): m = (9.00 - 7.00) / (1.950 - 2.250) = 2.00 / -0.300 = -6.6667
  4. Perhitungan Offset (b): b = 7.00 - (-6.6667 × 2.250) = 7.00 - (-15.000) = 22.000
  5. Pengujian Air Kolam: Sensor membaca tegangan V = 2.100 V.
  6. pH = (-6.6667 × 2.100) + 22.000 = -14.000 + 22.000 = 8.00. Nilai 8.00 dikirim ke FastAPI!

fastapi_backend/main.py — Core Ingestion & MJPEG Proxy
from fastapi import FastAPI, WebSocket, WebSocketDisconnect, Response
from fastapi.responses import StreamingResponse
from pydantic import BaseModel, Field
import httpx

app = FastAPI(title="Water Monitoring IoT Backend", version="1.0.0")

class SensorReadingCreate(BaseModel):
    temperature: float = Field(..., description="Suhu air dalam Celsius")
    ph: float = Field(..., ge=0.0, le=14.0, description="pH terkalibrasi")
    turbidity: float = Field(..., ge=0.0, description="Kekeruhan NTU")
    relay: bool = Field(default=False, description="Status relay")
    device_id: str = Field(default="esp32-sensor-01", description="Identifier node")

# Endpoint proxy streaming MJPEG dari ESP32-CAM (Port 81)
@app.get("/api/v1/camera/stream")
async def camera_stream_proxy():
    camera_url = "http://192.168.1.150:81/stream"
    async def mjpeg_generator():
        async with httpx.AsyncClient(timeout=None) as client:
            async with client.stream("GET", camera_url) as resp:
                async for chunk in resp.aiter_raw():
                    yield chunk

    return StreamingResponse(
        mjpeg_generator(),
        media_type="multipart/x-mixed-replace; boundary=frame"
    )
mjpeg_generator(), media_type="multipart/x-mixed-replace; boundary=frame" )

10. Modifikasi Firmware untuk Kirim Data ke FastAPI

Firmware sensor mengirimkan payload JSON terstruktur ke endpoint POST /api/v1/sensors/readings.

Tambahan pada watermonitoring_esp32.ino
#include <WiFi.h>
#include <HTTPClient.h>

const char* SSID = "NAMA_WIFI";
const char* PASS = "PASSWORD_WIFI";
const char* FASTAPI_URL = "http://192.168.1.100:8000/api/v1/sensors/readings";

void postReading(float t, float ph, float turb, bool relay) {
  if (WiFi.status() != WL_CONNECTED) return;
  HTTPClient http;
  http.begin(FASTAPI_URL);
  http.addHeader("Content-Type", "application/json");

  String body = "{\"temperature\":" + String(t, 2)
              + ",\"ph\":"            + String(ph >= 0 ? ph : 7.0, 2)
              + ",\"turbidity\":"     + String(turb >= 0 ? turb : 0.0, 1)
              + ",\"relay\":"         + String(relay ? "true" : "false")
              + ",\"device_id\":\"esp32-sensor-01\""
              + "}";
  http.POST(body);
  http.end();
}
